# docs/ - 项目文档

本目录存放项目相关文档。

## 文档结构

```
docs/
├── architecture/          # 架构与技术文档(入库)
│   ├── 系统架构.md        # 整体架构设计
│   └── API文档.md         # 后端 API 接口文档
├── 客户使用手册.md        # 客户侧安装操作指南(不入库)
└── 交付清单.md           # 交付物清单(不入库)
```

## 文档说明

### 架构文档 (入库,随代码演进)

- **系统架构.md**: 
  - 整体架构设计
  - 前后端技术栈
  - 目录结构说明
  - 核心模块详解
  - 数据流转过程
  - 打包分发流程
  - 扩展点说明

- **API文档.md**:
  - 后端所有 HTTP 接口
  - 请求/响应格式
  - 错误码说明
  - WebSocket 实时日志
  - 客户端调用示例

### 客户文档 (不入库)

这两份文档包含客户敏感信息(下载地址、联系方式等),不进版本控制:

- `客户使用手册.md`: 面向最终用户的安装和使用指南
- `交付清单.md`: 项目交付物清单

已通过 `.gitignore` 排除这两个文件。

## 文档维护原则

1. **架构文档跟随代码**: 重构时同步更新架构文档
2. **API 文档与接口一致**: 新增/修改接口时更新 API 文档
3. **客户文档独立维护**: 部署环境、联系方式等变更不影响代码仓库
4. **版本说明及时记录**: 每次发版前更新 CHANGELOG.md
